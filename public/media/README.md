# Ambient media

The application reads `manifest.json` and renders its built-in illustrated fallback whenever an asset URL is null. Null entries are intentional; no image or video is represented as generated until the corresponding file and provenance exist.

The requested production source is Higgsfield. The planned set is a warm rainy-cabin still, a quiet coast-at-dusk still, and a short muted ambient loop. Generation is explicitly paused by the owner. No provider activity is permitted until it is explicitly re-authorized; no substitute provider or fabricated video has been used.

When authorized assets are produced, keep the optimized files here and update the manifest with local `/media/` paths only. Record the actual model, generation date, and applicable usage terms in this document. Do not commit account identifiers, API credentials, private generation responses, billing records, or signed download URLs. A still image animated by CSS is not a generated video.
